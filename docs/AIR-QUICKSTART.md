# RustDesk Air quick start

Install the Apple Silicon Host on the Pro and the Intel Client on the Air from the matching release archives. Export a pairing file from the Host and import it on the Air. Keep that file private: it contains the connection secret. The Host needs Screen Recording and Accessibility permissions; the Client needs Local Network permission. During remote control, move the pointer to the top edge to choose a Space or use **Reload Spaces** if the chooser stops loading. Press Control–Option–Command–Escape to exit the Air session.

The apps are development previews and are signed but not Apple-notarized. The repository contains no pairing file or user-specific network configuration.
